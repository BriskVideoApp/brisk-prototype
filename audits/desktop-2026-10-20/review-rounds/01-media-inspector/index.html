Recommended changes

Design proposal for approval. The diagrams below explain layout behaviour; they are not current screenshots, rendered product mockups or verified fixes.

1. A protected header

Start the panel below the Media page heading/search and global navigation. Keep Filename and Close visible while its content scrolls. Use Brisk's approved quiet Close control.

2. Dock only when it fits

Keep the existing panel width. Dock when enough room remains for readable files. Otherwise overlay the right of the Media workspace, preserving its underlying layout. Do not automatically collapse navigation.

3. Predictable keyboard entry and exit

Select must select; opening must open. Keyboard opening moves focus into the inspector. Close or Escape returns focus to the opening file. Inner menus consume Escape first. The inspector stays non-modal, with no click-away dismissal.

4. Preserve location and unfinished work

Keep the Client, project, folder, filters, selected files and scroll position. Before closing or switching files with an unsent comment, use the existing confirmation pattern to keep editing or discard. Preserve current rename saving.

Trade-off: an overlay covers browsing while open on constrained layouts. Closing returns to the unchanged file location. A permanently docked panel keeps everything beside each other but reproduces the current squeeze; automatically collapsing rails changes navigation without an explicit choice.

What stays

Brisk styling, the preview, metadata, Details/Comments/Transcript tabs, role-specific actions, filename save behaviour and location context. Apply the shared inspector behaviour to global and project Media, checking each consumer independently.

Outside this first pass: bulk-selection policy, folder grouping, Shoot progress, Transcript paragraph shortcuts and mobile design.

Supporting example

Google Drive on Mobbin keeps file identity and Close at the top of a right details panel below its app header. This supports retaining the side-panel concept; it does not establish Brisk's breakpoints or override its DS.

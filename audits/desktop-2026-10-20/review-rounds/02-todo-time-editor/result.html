To Do time editor: the four agreed changes

The editor keeps its compact layout and now fits the visible workspace. The project name and actions stay reachable, invalid hours get clear feedback, and keyboard entry and exit preserve context.

What changed

1. Fits the screen

Measured placement opens above or below the time block, stays below the global header and follows workspace scrolling and resizing.

2. Reachable actions

A quiet Close sits beside the project name. Header and footer stay visible; only the fields scroll in a short window or with an enlarged Note.

3. Clear hours entry

The existing0.25-24 range and quarter-hour precision are explained. Invalid drafts disable Save and show feedback after leaving Hours. Valid saves retain the entered value.

4. Predictable keyboard use

Enter/Space opens with Stage focused. The Stage list handles its own Escape; a second Escape cancels and returns to the block. Close/Cancel also return focus.

Existing width, Stage / Hours / Note order, explicit Save/Cancel boundary and separate Delete remain. No board redesign, new date/status fields, time policy or permission changes.
